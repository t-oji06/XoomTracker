# XoomTracker

XoomTracker is a small full-stack fitness tracker with:

- User registration and login
- MongoDB-backed workout and calorie entries
- A weekly streak tracker
- A React frontend and Express/MongoDB backend

## Project Structure

- `client/` contains the React app
- `server/` contains the Express API

## Running Locally Or On Codio

Open two terminals.

### Backend

```bash
cd xoomtracker_full/server
npm install
npm start
```

### Frontend

```bash
cd xoomtracker_full/client
npm install
npm start
```

The frontend should open on port 3000 and call the backend on port 5000.
